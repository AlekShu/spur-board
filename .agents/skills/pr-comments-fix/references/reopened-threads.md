# Reopened review threads

- Resolve every thread you answered: an answered but unresolved thread still returns the task to
  Dev (`requireResolvedThreads`, `docs/how-board-works-columns.md`).
- A reviewer who disagrees with your answer reopens the thread. Treat it as new work.
- Reply to the reviewer comments after your last reply, then resolve the thread again.
- No reviewer comment after your last reply -> ask once in the thread what is still missing and
  leave it unresolved.
- Do not repeat the question in a later round; it stays visible in the thread.
